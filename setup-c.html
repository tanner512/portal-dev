First · Check that you need this
🤔

Do you actually need the mini?

The mini (togo-mini) is the always-on shared box: PHI stays there and the scheduled automation runs there.

You need it if your work touches PHI storage, the recruiting/CMS scrapers, the patient-sync agents, or a production extract.

✅
You do not need it to develop the EMR. Nothing in card B depends on it — localhost is fully self-contained on sandbox data.
✋
If nobody has told you that you need the mini, you don’t. Close this page; it is ten minutes to add later.
Phase 1 · Get on the tailnet
✉️

Ask for an invite

[YOU]

Ask an admin for a Tailscale invite.

⚠️
Accept it with your @togohealth.com account, not a personal one. The tailnet is keyed to the work domain — an invite accepted with a personal Gmail joins the wrong tailnet and then fails in a way that looks exactly like a network problem.
🔓

Install and connect

brew install tailscale

sudo tailscale up
sudo tailscale up

Verify — the mini should be listed:

🧭
Card B deliberately leaves tailscale out of its install line. An unused VPN client that silently fails to connect is a red herring that costs a day on a machine that never needed it.
Phase 2 · Reach the mini
🏷️

Hostname, never an IP

The mini is always:

togo-mini.tail027aaa.ts.net
togo-mini.tail027aaa.ts.net

That is Tailscale MagicDNS — it resolves to the right address even when the underlying IP changes.

✋
Never hardcode an IP in a script, a config, or a note. They do change, and the failure shows up weeks later as “the mini is down”.
🔑

SSH access

[YOU]

Send Greg your public key from card B:

cat ~/.ssh/id_ed25519.pub
cat ~/.ssh/id_ed25519.pub

He adds it to the togomini account. Then test:

ssh togomini@togo-mini.tail027aaa.ts.net
ssh togomini@togo-mini.tail027aaa.ts.net
🚫

Nothing to install for monitoring

The old laptop-side monitor (com.togohealth.minicheck / check-mini.sh) was retired 2026-07-17.

✋
Do not reinstate it. It fired an alert on every laptop whenever any laptop’s own VPN dropped — which is not the mini being down.
When it says “the mini is down”
🔍

Run one command before anything else

tailscale status
tailscale status
  • It errors, or the mini is not listed → it is your Tailscale. Open the app or sudo tailscale up.
  • The mini is listed but SSH hangs → your key is not on the togomini account yet, or the mini is genuinely offline. Ask Greg before assuming the second.
📈
The order matters: almost every “mini is down” report has turned out to be the reporter’s own tailnet session having expired.

Four rules for the mini

Short list, and the first one is the reason the box exists at all.

🔒 PHI lives there, not here

That is the whole reason the box exists. Do not copy PHI down to your laptop to “work on it locally”.

🧭 It is usually a lane boundary too

Work that reaches the mini normally belongs in togo-facility-tools or personal, not the EMR lane. Check which lane you are in before you start.

🏷️ MagicDNS name, always

togo-mini.tail027aaa.ts.net. If you find a hardcoded IP anywhere, replace it — that is a latent outage.

💼 @togohealth.com, always

Both the Tailscale invite and the sign-in. A personal account silently joins the wrong tailnet.
