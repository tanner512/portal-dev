Why this is four pages and not one

The setup used to be a single prompt that opened by asking two questions — do you need Command access? and do you need Tailscale? — and those two questions were the part people kept getting wrong.

❓ Answered wrong, or answered late

A wrong answer meant a half-installed VPN client that silently fails to connect, or an empty ~/claude/command that loads lane rules with no repo behind them. Answered late, the folder tree had to be redone.

✅ A and B now ask nothing

They build a complete, working EMR machine on their own. Nothing in either depends on Tailscale or Command.

🧭 C and D are opt-in, not opt-out

You do them afterwards, only if someone has told you that you need them. If nobody has, you don’t — and either is about ten minutes to add later.

📖 Read them in order

A → B, then C and/or D if they apply. Each page carries its own prerequisites at the top.
