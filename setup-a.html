TogoHealthMachine Setup A · Before Claude

Six commands
to a working Claude

Everything you do on a brand-new Mac before Claude exists on it — two apps, one login, and six commands you paste one at a time.

No Claude in this card. It is all you, and it ends with Claude Code running so you can hand the rest over.

Before you touch a terminal: ask an admin for two things — a GitHub account added to the togohealth-dev org, and a @togohealth.com Google account.

Nothing else is asked of you. No “do you need Tailscale?”, no “do you need Command access?” — those are separate optional cards you do afterwards. This one builds the same machine either way.
Phase 1 · Two apps and a loginall clicking — no terminal yet
🌍

🖱️ Install Chrome, then pin it

[YOU]

Download from google.com/chrome, open the .dmg, drag Google Chrome into Applications, then eject the disk image.

Open it, then right-click the Dock icon → Options → Keep in Dock.

📌
You will live in this browser: the tracker, claude.ai, the portal on localhost, and the Google account below all run here.
🔑

Sign in with @togohealth.com

[YOU]

Chrome → profile icon (top right) → Sign in → your @togohealth.com address. Leave that profile open.

This one account gets you the portal login, the tracker, Drive — and Tailscale later, if you ever do card C.

⚠️
The single most common way a new machine ends up half-working: signing in here with a personal Gmail. The tracker loads, the portal login does not, and nothing tells you why.
⌨️

Pin Terminal to the Dock too

[YOU]

Finder → Applications → Utilities → Terminal. Open it, then right-click the Dock icon → Options → Keep in Dock.

You do not need to understand the terminal. You need to be able to find it, and paste into it.

Five things that trip people here

Every one of these has cost a real person real hours on this exact card.

🔒 Never paste a credential into Claude

Claude fetches what it needs from Secret Manager itself. If any step seems to want you to paste a password or key into the session, stop and ask Greg.

❓ It asks you nothing about Tailscale or Command

On purpose. Those are cards C and D, done afterwards only if someone has told you that you need them. If nobody has, you don’t.

🛑 One command at a time, really

The six are ordered because each one needs the last to have finished. Batch-pasting is the single most common way this phase goes wrong.

🍎 Mac first

These steps are written for a Mac. On a PC the Dock steps become taskbar pins and the installers differ — switch the tab on any code block, and ask Greg before improvising.

📖 Then read “How We Ship”

This card gets your laptop ready. How We Ship explains what happens to a project once you start building.
